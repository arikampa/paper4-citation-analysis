# Reproducibility notes

## Execution environment

The notebooks were authored for **Google Colab** and extensively reference an author-specific project folder beneath `/content/drive/MyDrive/`. The code was intentionally **not refactored across the 14 notebooks**, to avoid silently changing research logic. A user must replace those literal `BASE_DIR`, `PROJECT_ROOT`, `PDF_DIR`, `DATA_PATH` and similar variables with their own locations before running.

Example: mount Google Drive via `google.colab.drive.mount('/content/drive')`, create a project folder, place required inputs there, and update notebook-level configuration variables accordingly.

Do not assume that cloning this repository alone enables the published runs. Full environment pinning, random seeds, validation of original splits and exact GPU/CUDA package versions should be documented before a formal reproducibility claim.

## Key working files

- `clean_dataset.csv`: produced by 01; local metadata set required for 03, 06, 07.
- `oa_pdf/`: downloaded PDFs produced by 02, intentionally excluded.
- `coverage_sampling_plan/milestone_sampling_plan.csv`: produced by 03 and necessary for later milestone filtering; a supplied copy is in `data/derived/coverage_sampling_plan/`.
- `rare_citations_summary.csv`: generated by the factorized inference notebook 05 and provided under `data/derived/` as a limited derived output.
- `milestones_journal_level/`: produced by 06 and populated further by 07; the public draft retains **selected** tables and diagrams, not every per-paper input, prediction or snapshot.
- Model directories used by 05 (citation detection, sentiment, citation function) and training checkpoints are external and not supplied here.
- OpenAlex API key: in the citation extraction notebook obtained from Colab user data; supply credentials through secure secret storage.

## Dataset construction dependencies

The available workflows reference ACT2, Athar/ACL, MultiCite JSON, a clinical-citation corpus, journal citation sets, and two synthetic citation datasets. Those data files are not redistributed in this public draft pending permission, provenance and label-mapping review. The supplied archives contain additional audit files. Consult `data/README.md` and `docs/FILE_MAP.md`.

## Statistical analysis outputs

Four cumulative PDF-coverage milestones are represented: v1=30%, v2=50%, v3=70%, v4=100%. Model association/inference and delayed-recognition outputs are preserved selectively in `results/milestones/`. The named inferential/predictive tables retain the source results as supplied, with no numerical modifications.

The ZIP bundle does not claim that output tables or model conclusions have been independently verified. Before publication, run 06 and 07 on the frozen inputs, compare stable output checksums or rowwise values, and reconcile all main manuscript tables/figures.

## Runtime validation checklist

1. Establish a clean Colab environment with compatible Python, CUDA, PyTorch and Transformers versions.
2. Set `HF_TOKEN`, `WANDB_API_KEY`, and `OPENALEX_API_KEY` only where required, using secrets management. Rotate exposed credentials.
3. Verify the source and redistribution terms of all inputs.
4. Rebuild the `clean_dataset.csv` and `oa_pdf/` inputs, recording date/query filtering and HTTP failures.
5. Regenerate the same sampling plan and compare source counts for the four milestones.
6. Recreate or obtain exact training data, source splits and model versions; record seeds, checkpoint identifiers, and software versions.
7. Run 05/06/07; verify the number of analyzed articles, LFCR/LFC availability, statistical estimates, uncertainty intervals and sensitivity tables against the manuscript.
8. Cite the original source corpora and OpenAlex data sources.
